# Local semantic models and score conventions

Decisions established before implementation, 19 October 2026.

- Bi-encoder: [sentence-transformers/all-MiniLM-L6-v2](https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2), Apache 2.0, pinned revision `1110a243fdf4706b3f48f1d95db1a4f5529b4d41`. Lightweight 384-dimensional English embeddings on CPU. Minimal whitespace normalization only; no geographic information enters embedding. Longer texts are token-chunked and averaged, then normalized. Exact NumPy dot products compare the complaint to **all** compatible active cluster centroids. Assignment uses `similarity >= 0.62`, configurable; this is a starting heuristic evaluated by `scripts/evaluate_models.py`, not an accuracy claim.
- Cross-encoder: [cross-encoder/stsb-TinyBERT-L4](https://huggingface.co/cross-encoder/stsb-TinyBERT-L4), Apache 2.0, revision `1f478482145797a0cac02d6b9ab3c65c9d25fb1e`. English STS benchmark model. Explicit `torch.nn.Sigmoid()` activation transforms one logit to a bounded similarity in [0,1], as used by its STS model convention. **This is not a calibrated probability.** Merge requires `score > 0.92` (strict; equality does not merge), independently configurable from assignment. The strict default can leave similar issues separate. STS is a conservative baseline, not a civic-domain-trained equivalence detector.

Centroid similarities >=0.55 nominate the five closest pairs per iteration; a maximum of three merges per complaint. For clusters with multiple members, compare their centroid representatives and the farthest member pair; both scores must pass to reduce drift. After every merge, recompute candidates using the new centroid. No transitive connected-component merging. Canonical ID is the oldest cluster, with ID breaking timestamp ties. All member embeddings determine the normalized mean, representative and count. Full cluster labels derive from TF-IDF phrases in their own texts, not fixed civic categories.

Models load lazily once per process in the serialized worker. Runtime uses `local_files_only=True`; setup explicitly enables downloading and preloads both models into the local Hugging Face cache. Initial installation needs internet; runtime inference requires no network. The API never waits for model loading/inference on submission. Retries are durable and bounded; restart recovers `processing` rows. Use one Uvicorn worker.

Changing the embedding model/revision requires a complete explicit re-embedding/reclustering operation; mixed vector versions raise an error rather than silently comparing incompatible vectors. No multilingual performance claim: the selected models are English. Other original-language text is accepted without translation, but quality is unverified.
